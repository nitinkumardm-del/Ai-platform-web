# AI Website (React + Vite + Tailwind + React Router)

A simple multi-page site inspired by modern SaaS designs like editinglive.com.

## Features
- React + Vite + TypeScript
- Tailwind CSS with **Dark Mode** (`class` strategy)
- React Router (Home, Features, Pricing, Contact)
- Responsive Navbar + Footer
- Framer Motion for subtle animations
- Lucide icons

## Getting Started

```bash
npm install
npm run dev
```

Open the dev server URL printed in your terminal.

## Build for Production
```bash
npm run build
npm run preview
```
